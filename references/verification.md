## Agent 与网页往返

`npm test` 实际生成 7 秒、48kHz 单声道 PCM 测试音频，随后通过 CLI 创建含日文镜头、中文图层、原生转场、画面效果和关键帧的工程。测试在真实中文网页中完成以下操作：

1. 用原版文件输入打开 AI 工程，逐项确认网页镜头与 Agent 镜头相同。
2. 用原版按钮锁定首行；在新增面板修改第二行位置与旋转，再用原版下拉框更换组件。
3. 在原版时间输入修改 AI 显式固定的镜头时间，实际执行撤销/重做；修改歌词并撤销。
4. 保存与读取浏览器工程库，用原版保存按钮下载完整工程。
5. 执行原版随机编排，确认锁定镜头不变；用原版方案历史恢复 AI 参数。
6. 选择行范围，通过原版按钮实际下载 LRC、AE JSON、透明 PNG ZIP 和 MP4。
7. AI 重新读入网页保存的工程，仅修改第三行，确认已锁定首行的完整配方逐项相同，然后导出最终视频。

补充检查验证了工程快照往返、额外事件不重复、锁定行/图层拒绝修改、关键帧插值、opacity=0 的真实透明像素、歌词编辑保留 LRC 时间标签、转场期间字幕仅合成一次，以及附加图层的原生背景图形。网页测试无 JavaScript 异常。

测试解析 ZIP 本地文件头并解码真实 PNG；MP4 通过浏览器视频解码、seek、Canvas 读像素和 AudioContext 音轨解码检查。MP4 写入真实浏览器 OPFS 文件流，再分块保存到磁盘。

原来的 720p–4K 与 24/30/60fps 导出路径保留；本轮视频验收采用 360p/24fps，未执行完整 4K 视频性能验收。编码速度及 H.264/AAC 支持由设备决定。H.264 不支持透明背景，透明素材使用 PNG ZIP；没有 AAC 编码能力时 CLI 同时保存 WAV。原版 AE JSON 是其历史近似导出，仅用于该原功能；双向完整工程交换使用 `.jizura.json`。
