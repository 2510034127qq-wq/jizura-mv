# 本地源码审计

基线：官方仓库本地 `fc16bfe`，版本 `0.10.1`。在真实 Chromium 页面内加载全部源码，并从 10 类注册表读取结果，再与 `git show` 取出的原始基线逐方法比较（统一 CRLF/LF 后计算 SHA-256）。

额外两个注册布局为 `layout.title` 和 `layout.interlude`；27 套风格完整保留。`upstream-components.json` 保存基线方法哈希和风格定义，`components.json` 是 AI 可检索的完整目录。所有原组件及绘制函数均保留，无合并、替代或 AE 近似实现。

原实现是有序加载的 JavaScript 注册式组件、Canvas2D 绘制、原生规划器、WebCodecs 视频编码与本地 mp4-muxer。各组件闭包会共享辅助函数，故以原生源文件为不可分割实现单元，调用时按组件 ID 解耦，避免为“独立文件”拆散闭包导致视觉变化。Agent 无须加载编辑器 DOM；网页和 Agent 加载完全相同的 39 个共享原生文件。

原生改动限于字体加载入口、UI 的工程读写/资源保存/参数与历史联动，以及渲染入口的一个可选条件：透明附加图层也可绘制原生背景图形。所有组件函数与规划、绘制算法保持原样。新增 `runtime/project.js` 提供统一参数、关键帧、图层、快照和锁定检查；新增编辑器面板保留原 UI 的全部控件。原始纹理算法在同步调用边界获得种子化随机源，使重复输出稳定，纹理算法本身不变。

原字体依赖 Google Fonts，仓库未提供字体文件。Skill 附带从原 family/weight 请求得到的完整字体文件、CSS、来源和每个字体的 OFL；不对字形重新抽样或替换。上传的音频和自定义字体嵌入工程，原生工程字段与 Agent 扩展均为可序列化 JSON。
